3. [Getting Hands On with NetBox Discovery and Assurance](sections/Section-3/Section-3.md)

5. [Introducing Git Driven Configuration Management for NetBox Discovery](sections/Section-5/Section-5.md)

Each section contains instructional materials and hands-on exercises.
